# 🛒 FreshMart Supermarket

A responsive supermarket website built with HTML, CSS, and JavaScript.

FreshMart is a front-end web project designed to provide customers with an easy way to explore supermarket products, search for products, and contact the business.

## ✨ Features

- Responsive supermarket website
- Product categories and product listings
- Product search functionality
- Customer contact form
- WhatsApp ordering link
- Responsive design for different screen sizes
- Clean and modern user interface
- Organized multi-page website

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Formspree
- Git & GitHub
- GitHub Pages

## 📄 Pages

- **Home** — Introduction and featured products
- **Products** — Browse and search available products
- **Contact** — Contact information and customer message form

## 🎯 What I Learned

While building FreshMart, I practiced:

- Creating multi-page websites with HTML
- Building responsive layouts with CSS
- Using JavaScript to create interactive features
- Implementing product search functionality
- Connecting an HTML form to Formspree
- Organizing website assets and images
- Deploying projects with GitHub Pages
